openai-balance

Your OpenAI API credit above the prompt: an estimated balance with a gauge, today's spend, and the model and key of the last call.

■ See what's happening Version 0.1.0

Install

$ claude plugin marketplace add hamzafer/claude-code-mods
$ claude plugin install openai-balance@claude-code-mods

Restart Claude Code after installing. To try it without installing, clone the repo and run claude --plugin-dir mods/openai-balance.

How to use

Give it an OpenAI organization Admin key (read-only is enough) in /config, then set your balance once from the Billing page:

/openai-balance 25.00

Run /openai-balance with no amount for the full breakdown. Set it again after a top-up.

How it behaves

  • The balance is an estimate: OpenAI has no balance API, so it is the amount you set minus the spend the Costs API reports since then.
  • Green from $5, yellow under $5, red under $2.
  • Shows the model, key name and time of the newest call. Decisions API calls show as spend only, until OpenAI's Usage API covers them.
  • The key comes from /config, else OPENAI_ADMIN_KEY, else the macOS Keychain item openai-admin-key, and stays in memory.
  • Refreshes every 10 minutes and after each turn. A failed refresh keeps the last numbers, marked offline.
  • Narrow terminals drop the gauge first.

Needs

  • Claude Code 2.1.287 or newer
  • An OpenAI organization Admin key
