switchboard

Picks the model for each subagent that doesn't name one, from its short label only, and shows what every subagent cost.

■ Spend less Version 0.3.3

Install

$ claude plugin marketplace add hamzafer/claude-code-mods
$ claude plugin install switchboard@claude-code-mods

Restart Claude Code after installing. To try it without installing, clone the repo and run claude --plugin-dir mods/switchboard.

How to use

It starts with the picker off: it only tracks cost. Pick openai or jev under Picker in /config and add a key, then try Mode suggest for a few days before auto. See every subagent with its pick and cost:

/route

How it behaves

  • A named model is kept. When you or your CLAUDE.md name a model for a subagent, switchboard leaves it alone. Only a subagent with no model named gets a pick.
  • Only the label goes out. The picker gets the subagent's type and its 3 to 5 word label, never its task text, so code, paths and pasted keys never leave your machine.
  • Pickers: OpenAI's Decisions API (about $0.00003 a pick) or Jev (about $0.00001 a pick, direct or through Vercel AI Gateway).
  • Models: haiku-sonnet-opus (default) or sonnet-opus-fable. Style: saver, the cheapest model that will do the job well, or quality.
  • No picker, no key or no answer within 4 s: nothing changes, and /route says why. Under 50% sure, it shows the pick but keeps the model.
  • Leaves forks and teammates alone. Costs are estimates at API prices, not what your plan charges.

Needs

  • Claude Code 2.1.287 or newer
  • For picks: an OpenAI key, a TypeSafe key or a Vercel AI Gateway key
