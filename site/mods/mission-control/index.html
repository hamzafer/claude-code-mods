mission-control

Every subagent, every tool call and every file they touch, in a pane next to the chat.

■ See what's happening Version 0.1.2

Install

$ claude plugin marketplace add hamzafer/claude-code-mods
$ claude plugin install mission-control@claude-code-mods

Restart Claude Code after installing. To try it without installing, clone the repo and run claude --plugin-dir mods/mission-control.

How to use

/mission
Opens the map
/mission code
Opens straight to the code map
/mission who
Opens straight to the agents
w
Who: the agents and every tool call, live
c
Code: the code map, with import arrows
q
Closes it

How it behaves

  • A file glows blue while Claude reads it, orange while it edits it, and turns green with a check once changed.
  • One Haiku call after each turn writes the line under each changed file.
  • Headless Chrome draws the code map as an image, in a throwaway profile.

Needs

  • Claude Code 2.1.287 or newer
  • The Code view needs macOS, Google Chrome and a terminal that shows images (Ghostty, kitty, iTerm2). The Who view works everywhere.
