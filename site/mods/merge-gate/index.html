merge-gate

Holds gh pr merge until CI passes and one Codex review has run. A PR line above the prompt, and /gate shows the PR's status.

■ Fork and adapt Version 0.1.4

Install

$ claude plugin marketplace add hamzafer/claude-code-mods
$ claude plugin install merge-gate@claude-code-mods

Restart Claude Code after installing. To try it without installing, clone the repo and run claude --plugin-dir mods/merge-gate.

How to use

/gate
Shows the PR's status
/gate rerun
Reruns the failed CI jobs
Hold / Merge anyway
Your answer when CI or the review is missing

How it behaves

  • If CI or the review is missing, it asks you: Hold or Merge anyway. With no one to answer, it holds.
  • Refuses a codex review that doesn't set the one fixed model. Change the model in hooks/register.tsx to yours.
  • Refuses a second review of the same PR, and any codex exec.
  • Refuses any review while ~/.codex/config.toml points at a local Ollama server.
  • A review counts when it starts, so a quota error doesn't buy a retry.

Needs

  • Claude Code 2.1.287 or newer
  • gh
  • The Codex CLI
