glance

One line above the prompt with what needs you: next meeting, PRs, Linear issues and Slack DMs.

■ Fork and adapt Version 0.1.0

Install

$ claude plugin marketplace add hamzafer/claude-code-mods
$ claude plugin install glance@claude-code-mods

Restart Claude Code after installing. To try it without installing, clone the repo and run claude --plugin-dir mods/glance.

How to use

/glance
Refreshes and lists everything behind the line

How it behaves

  • One item per source, the most urgent one, with "+2" for the rest.
  • Calendar: the meeting on now, or the next one. Skips all-day events, ones you declined, and blocks over 3 hours already running.
  • PRs: a review asked of you, then your PR with failing CI, then one with changes requested.
  • Linear: your issues In Progress or In Review, last touched first.
  • Slack: DMs and channel @mentions from people (no bots) in the last 2 hours.
  • Fetches at start, then every 5 minutes. Connector calls cost no model tokens.

Needs

  • Claude Code 2.1.287 or newer
  • gh
  • The claude.ai Google Calendar, Linear and Slack connectors. A source that's missing just stays off the line
