now-playing

What Spotify is playing, one line above the prompt: track, progress and the lyric being sung, with ⏮ ⏸ ⏭ buttons.

■ For fun Version 0.1.0

Install

$ claude plugin marketplace add hamzafer/claude-code-mods
$ claude plugin install now-playing@claude-code-mods

Restart Claude Code after installing. To try it without installing, clone the repo and run claude --plugin-dir mods/now-playing.

How to use

/music
Plays or pauses
/music next, /music prev
Skip
⏮ ⏸ ⏭
Click them at the end of the line (Claude Code in fullscreen)
ctrl+x, Tab
Reach the line, then b previous, p play or pause, n next, Esc to go back

How it behaves

  • Paused, the line dims to the track and artist. Spotify closed, the line goes away. The mod never opens Spotify.
  • The lyric shows a moment early and moves 4 times a second, so it keeps up with the singing.
  • For songs in right-to-left scripts it looks for romanized lyrics instead.
  • The first time, macOS asks once to let your terminal control Spotify (Automation). Allow it, or the line stays empty.
  • For lyrics it sends the track, artist and album names to LRCLIB, once per track. Turn lyrics off in /config and nothing is sent.

Needs

  • Claude Code 2.1.287 or newer
  • macOS
  • The Spotify desktop app. It reads Spotify through AppleScript, so there is nothing to log in to
