gotham-night

Searchlights while Claude works. The signal, and a burst of bats, when it needs you.

■ Themes Version 0.2.3

Install

$ claude plugin marketplace add hamzafer/claude-code-mods
$ claude plugin install gotham-night@claude-code-mods

Restart Claude Code after installing. To try it without installing, clone the repo and run claude --plugin-dir mods/gotham-night.

How to use

  • Nothing to run. Start a local session in the Code tab of the Desktop app and send a message: the city comes up behind the chat.
  • To take the look off, turn the mod off, start a new session, then open Settings, search for code appearance and choose Remove colors.

How it behaves

  • While Claude works, two searchlights sweep a rainy city of gothic towers under a full moon, with flickering windows, a blinking beacon and fog. Forked lightning strikes behind the skyline, an elevated train crosses the rooftops and an airship drifts under the clouds.
  • When Claude needs you (its turn ended, it asks you a question, or a permission prompt is still waiting after 1.5 seconds), lightning hits the tower and every window in the city goes dark. Then the signal ignites on the clouds, a red flare rises, the windows flicker back on and a burst of bats scatters.
  • Every burst is new: it comes from the signal, the rooftops, either side or the sky, with its own paths and timing.
  • There is no event for the moment you approve a permission prompt, so after you approve one the signal stays lit until that tool finishes. Background subagents and other plugins' tool calls never change it.
  • Night-black colors with a signal-yellow accent, dark mode only. The terminal draws no theme, so there it does nothing. Your system's reduced-motion setting stills the scene and hides the bats.

Needs

  • The Claude Code Desktop app
  • Claude Code 2.1.324 or newer in its Code tab
