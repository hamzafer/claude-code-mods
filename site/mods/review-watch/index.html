review-watch

A live line above the prompt for each running code review: Codex or a review subagent, its model, what it reviews, time, and Codex's latest output. A toast with the findings when it ends.

■ See what's happening Version 0.1.0

Install

$ claude plugin marketplace add hamzafer/claude-code-mods
$ claude plugin install review-watch@claude-code-mods

Restart Claude Code after installing. To try it without installing, clone the repo and run claude --plugin-dir mods/review-watch.

How to use

Nothing to type. Install it and the line shows above the prompt. It hides when it has nothing to show.

How it behaves

  • Tracks every codex review shell command, in the foreground or background, and every subagent whose description says "review".
  • Each line shows the model (from -c model=... or --model, else your ~/.codex/config.toml), the --title or what's under review, and the elapsed time.
  • When a review ends, a toast says so. For Codex it also counts the [P1] and [P2] findings, when the output goes to a file or the review runs in the background.
  • If it can't read a Codex review's output, the toast has no findings count. It never guesses "no findings".
  • A finished review shows a ✅ line for 30 s, then goes away.

Needs

  • Claude Code 2.1.287 or newer
  • ps and tail (macOS and Linux have both)
