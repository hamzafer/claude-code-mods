session-saver

Names untitled sessions through unpause. /park saves where you left off, and a resumed session shows it.

■ Fork and adapt Version 0.1.2

Install

$ claude plugin marketplace add hamzafer/claude-code-mods
$ claude plugin install session-saver@claude-code-mods

Restart Claude Code after installing. To try it without installing, clone the repo and run claude --plugin-dir mods/session-saver.

How to use

/park
Saves where you left off. Then unpause open <name> to resume
/park <note>
Adds your own note, shown under the summary on resume

How it behaves

  • The note shows until you type.
  • Untitled sessions get a name after their second turn.

Needs

  • Claude Code 2.1.287 or newer
  • unpause (github.com/hamzafer/unpause)
