snake

Snake in a pane while Claude works, paused when it's done. Opt-in, so nothing opens until /snake.

■ For fun Version 0.2.3

Install

$ claude plugin marketplace add hamzafer/claude-code-mods
$ claude plugin install snake@claude-code-mods

Restart Claude Code after installing. To try it without installing, clone the repo and run claude --plugin-dir mods/snake.

How to use

/snake
Starts the game. Type it again to turn it off
stop
Turns it off

How it behaves

  • Installing it changes nothing until you type /snake.

Needs

  • Claude Code 2.1.287 or newer
